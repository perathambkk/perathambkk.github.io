จากเริ่มมีเหตุปี 2561 2562 คอนโดซื้อปี 2549 อยู่จนราวๆตั้งแต่ 2553 2554 ที่ปกติเรียนอยู่นอก ไม่ค่อยอยู่ห้อง กลับไทยปีละไม่กี่วัน กลับมาเพราะเจอตอนปลายปีปีใหม่ 2561 มีเาียงแปลกๆ ออกจากกำแพงห้อง 1/172 1/173 กุมภา 2562 คุณตรึงใจแจ้งว่าเป็นมะเร็ง มีอะไรลงมาจากเพดานไม่รู้ในห้อง 1/171 เริ่มมีสารพิษ แก๊ส รั่วใส่ ปัจจุบัน คดียังไม่มีการส่งฟ้อง หรือแต่งตั้งทนาย ส่งไปปปช.ร้องเรียนไม่คืบ มีที่ที่รับเรื่องแต่ยังไม่ได้ดำเนินการเพราะยังไม่ได้ไปลงร้องเรียนคือ ศาลปกครองสูงสุด กับ สำนักอัยการสูงสุด ที่เหลือส่งเรื่องไปน่าจะทุกที่เช่น สคบ. จเรตำรวจ สำนักผบ.ตร. กองบัญชาการกองทัพไทย กองทัพบก กระทรวงกลาโหม กรมควบคุมมลพิษ กระทรวงสาธารณสุข แพทยสภา พยาบาลสภา วิศวกรรมสถาน สภาทนายความ กระทรวงการพัฒนาสังคมและความมั่นคงของมนุษย์ (พม.) กระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม (ทส.) กทม. ศูนย์ดำรงค์ธรรม (แจ้งตั้งแต่ ประวิตร อนุทิน เป็นรัฐมนตรีอ่ะ ประวิตรส่งจดหมายมาบอกให้ไปส่งผู้ว่ากทม. อนุทินให้ลูกชายมาคุยทีนึง) สำนักนายกรัฐมนตรี (แจ้งตั้งแต่ 2564 2565 ประยุทธ์ เศรษฐา แพทองธาร อนุทิน) ดีเอสไอ กระทรวงยุติธรรม (ยธ.) ฯลฯ

เคยไปแจ้งความสน.ทุ่งมหาเมฆตั้งแต่เกิดเหตุ 2562 2563 มีสารวัตรรับเรื่องและมาสืบ พบว่าโดนย้ายไปแล้ว สันนิษฐานว่าต้นเหตุจากพวกก่อเรื่องที่เห็นในโซเชี่ยวมีเดียช่วงปี 2561 เคยแจ้งความสน.ลุมพินี มีรองสารวัตรรับเรื่อง รับแจ้งความ ส่งเรื่องเบิกอุปกรณ์เอาอาวุธที่ฝังออกในสะบบของสตช. ทางระบบปฏิเสธและลบเรื่องทิ้ง รวมถึงแจ้งความ สน.ยานนาวา มีร้อยเวรบอกว่า ไม่เข้าใจศิลปินเลย

ทหารบางคนบอกว่า ก็มองเหมือนรบกับประเทศเพื่อนบ้าน รบชนะ ฆ่าแม่งให้หมด ไม่ก็ศิโรราบ ก็หวังเอาทรัพยากรทรัพย์สินไง

ทนายบางคนให้คำปรึกษาว่า เป็นคดีทุจริต ทำร้ายร่างกาย ทรมาน หน่วงเหนี่ยว แจ้งเท็จ หมิ่นประมาทและหมิ่นประมาทโดยโฆษณาโดยนัยและโดยตรง ปล้นชิงทรัพย์ ส่วนฆาตกรรมคุณตรึงใจก็อาจเป็นไปได้ โหดเหี้ยมมากถึงขั้นลงมือกับคุณตรึงใจในขณะป่วยมะเร็งด้วย รวมถึงท่าทีพลตรี อาจารย์ นายแพทย์ พีระพัฒน์ ที่ดูไม่ตรวจสารพิษ รวมถึงให้การขัดกับผมเป็นประจำ ให้การว่าไม่มีเหตุ เว้นแค่บอกว่าผมไม่บ้าเท่านั้นในใบรับรองแพทย์ใบนึง ซึ่งบางทีก็หาว่าผมบ้า ต้องเอาสินทรัพย์ไปตั้งผู้อนุบาล

มีเหตุว่า อาจารย์วิศวะ คอม จุฬา วิทยา คอม จุฬา ดูมีปัญหาตอนติดต่อทุกคนด้วย เช่นบางคนบอกว่าแม่ผมไม่ป่วยตอนเป็นมะเร็ง อะไรแบบนั้น หรือปล่อยข้อคิดเห็นในทางลบเกี่ยวกับผมรวมถึงแย้งผลการเรียน ไปจนถึงทรัพย์สินที่มี และไม่ดำเนินการจากเหตุทางโซเชี่ยวที่ควรจะเป็นตามจรรยาบรรณ คุณแม่ผมโดนทำร้ายก็บอกว่า ไม่มีวุฒิภาวะ อะไรแบบนั้น ซึ่งเลวร้ายผิดวิสัยคนปกติมาก ยังมีคนที่ใช้อุปกรณ์แอบดูที่ฝัง แอบดูในห้องคุณแม่ตอนยังไม่โอนมรดกที่อาคารสินธร เรสซิเดนซ์อีกด้วย ดูน่าสงสัยมากกว่าคนตามโรงพยาบาลอีก มีคนพิมพ์โพสต์ด้วย ว่าคอนโดสีลมแกรนด์เทอเรส เป็นครอบครัวผมโกงมา (แคปส่ง กับแจ้งทางจุฬาไปแล้ว ไม่พบอะไรเกิดขึ้น) ไม่ทราบว่าเกี่ยวกับที่ผมไปศึกษาต่อต่างประเทศอะไรหรือไม่ เพราะคนส่งไปไม่ได้มีแต่ครูที่ภาคที่ส่งจดหมาย มีครูต่างภาค ต่างคณะ กับราชการการทางพิเศษการบินไทย ราชการทหารอีก เพราะสอดคล้องกับเหตุบางอย่างที่เกิด เช่นการด่าเป็นบ้า ให้เสียหาย ไปจนถึงคดีต่างๆ รวมถึงเครือข่ายอื่นที่เกี่ยวข้อง
